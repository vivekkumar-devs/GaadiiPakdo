## 📖 Overview

**GaadiiPakdo** is a real-time Android transport tracking platform designed to connect passengers and drivers through continuous GPS synchronization and live map visualization.

The application supports both **User** and **Driver** roles within a single Android application and focuses on real-world usability, secure authentication, and responsive user experience.

---

## ✨ Key Features

### 🔐 Authentication & Security

- Phone Number + Password Login
- OTP-Based Password Recovery
- Strong Password Enforcement
- Password Visibility Toggle
- Single Active Session Login
- Separate User & Driver Access Control

### 📍 Real-Time Tracking

- Live GPS Tracking
- Firebase Realtime Synchronization
- Continuous Location Updates
- Real-Time Vehicle Visibility
- Distance Estimation
- ETA Calculation

### 👤 User Module

- Track Nearby Vehicles
- View Driver Details
- Direct Driver Calling
- Real-Time Vehicle Monitoring
- Improved Navigation Experience

### 🚘 Driver Module

- Broadcast Live Location
- Manage Driver Profile
- Vehicle Information Management
- Live Availability Updates

### 🎨 User Experience

- Modern Professional UI
- Ripple Touch Feedback
- Enhanced Map Navigation
- Improved Marker & Pin System
- Responsive Layouts
- Optimized User Flows
